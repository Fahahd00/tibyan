# سجل المكونات والمصادر

سجل لكل مصدر بيانات وأداة ونموذج وخدمة ومكوّن مفتوح المصدر استُخدم في تِبْيان: نوعه ومصدره والغرض منه وتاريخ أول
استخدام وأساسه النظامي أو رخصته، كما تشترطه وثيقة الشروط والأحكام للتحدي. التواريخ بتوقيت الرياض (UTC+3) وأُخذت من
سجل Git ومن تاريخ الجلب المحفوظ في كل لقطة.

**نصوص الفتاوى والأحاديث ملك لناشريها.** لا ينشر المستودع العام نصوصها، بل قائمتها فقط
([`data/corpus/manifest.jsonl`](../data/corpus/manifest.jsonl): المصدر والرقم والرابط وبصمة النص)، وتُنزَّل من
مواقعها الأصلية عند التشغيل. ونسخة الفهرس المستخدمة في النسخة المنشورة محفوظة في مستودع بيانات **خاص**.

## 3. أدوات التطوير المعتمدة على الذكاء الاصطناعي

| الأداة                                                  | المزوّد    | الغرض                                                                                                     | الفترة                    | الأساس                                                               |
| ------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------- | ------------------------- | -------------------------------------------------------------------- |
| Claude Code (مساعد برمجة)                               | Anthropic  | المساعدة في كتابة الكود والاختبارات والتوثيق وإعداد النشر وإنتاج الفيديو التعريفي، بتوجيه الفريق ومراجعته | 2026-10-04 إلى 2026-10-06 | شروط استخدام Anthropic                                               |
| ElevenLabs (نموذج eleven_multilingual_v2، صوت «Hijazi») | ElevenLabs | التعليق الصوتي العربي في الفيديوهين التعريفيين                                                            | 2026-10-06                | شروط ElevenLabs، خطة Starter المدفوعة (تتضمن رخصة الاستخدام التجاري) |

الفكرة وتصميم المنتج واختيار المصادر وقرارات الحوكمة الشرعية من الفريق. والفيديو التعريفي تسجيل حقيقي للموقع المنشور
بأداة Playwright، مع تعليق صوتي مولّد بالذكاء الاصطناعي عبر ElevenLabs، ورُكّب بأداة FFmpeg.
